## Question 2: FOMC merging process

**Answer:** Uses `pandas.merge_asof` with backward direction

**Details:**
- Script: `trend_code_submit/Analysis/fomc/align_predictions_and_score.py`
- Function: `merge_asof_by_stock()` (lines 85-134)
- Method: Backward-looking merge (no forward-looking bias)
- Process: For each stock and FOMC event, find most recent prediction ≤ announcement date

**Alignment algorithm:**
```python
# From align_predictions_and_score.py, lines 115-121
aligned_stock = pd.merge_asof(
    ev,  # FOMC events (left)
    g[["Date", "up_prob", "MarketCap"]],  # Predictions (right)
    on="Date",
    direction="backward",  # Most recent pred ≤ event date
    suffixes=("", "_pred")
)
```

**Rationale:**
- Weekly predictions (every ~5 days) vs. arbitrary FOMC dates
- Backward direction ensures no look-ahead bias
- Aligns on most recent Friday before announcement

**Example:**
```
FOMC announcement: June 15, 2020 (Wednesday)
Available predictions: June 5, June 12, June 19
→ Uses June 12 prediction (most recent ≤ June 15)
```

## Question 3: CNN architecture modifications from JKX

**Answer:** Same architecture as JKX; no modifications

**Architecture details (from `cnn_model.py`):**
- 3 convolutional layers (64 filters each)
- Kernel sizes: (5,3), (3,1), (2,1)
- MaxPooling after each conv layer
- Dropout: 0.50 (same as JKX)
- Activation: ReLU for hidden layers, Sigmoid for output
- Batch normalization: Yes
- Total parameters: ~1.2M

**Config parameters:**
```python
# From dgp_config.py
BENCHMARK_MODEL_LAYERNUM_DICT = {5: 2, 20: 3, 60: 4}
TRUE_DATA_CNN_INPLANES = 64  # 64 filters per layer
BATCH_SIZE = 128
DROP_OUT_PROB = 0.50
```

**Key difference from original:**
- Only train I20/R5 model (not all I5/I20/I60 combinations)
- Focus on single best-performing configuration

## Additional Implementation Details

- **Manual ingestion:** `FOMC_Dates_1936.csv` (scraped from Fed website)
- **Automated scraping:** `trend_code_submit/Analysis/fomc/scrape_calendar.py`

- **Output:** `CACHE_DIR/fomc/fomc_schedule.csv`, `fomc_schedule_with_offsets.csv`

### Training Script Entry Points
- **Main function:** `train_us_model()` in `cnn_experiment.py`
- **Model architecture:** Defined in `Model/cnn_model.py`
- **Data loading:** `Data/chart_dataset.py` (PyTorch Dataset)
- **Chart generation:** `Data/chart_library.py` (image drawing)

### Ensembling Details
- 5 independently trained models (different random seeds)
- Final prediction = average of 5 model outputs
- Each model trained separately on GPU
- Checkpoints saved: `new_model_res/D20L3F53S31D21MP21F53S11D11MP21F53S11D11MP21C64/model_*.tar`

## Summary for Methodology Section

### Scripts Pipeline
1. **Training:** `cnn_experiment.py::train_us_model()` → checkpoints
2. **Prediction generation:** `make_prediction_with_rets.py` → `weekly_prediction_with_rets.csv`
3. **FOMC schedule:** `ingest_manual_schedule.py` → `fomc_schedule.csv`
4. **FOMC windows:** `build_windows.py` → `fomc_window_returns.csv`
5. **FOMC alignment:** `align_predictions_and_score.py` → `fomc_decile_performance.csv`
6. **Portfolio generation:** `generate_cnn_portfolios.py` → portfolio CSV files

### Key Technical Details
- **Merge method:** `pd.merge_asof(..., direction="backward")`
- **Architecture:** 3 conv layers, 64 filters, dropout=0.50
- **Training:** Adam optimizer, lr=1e-4, 50 epochs, early stopping
- **Ensemble:** 5 models averaged
- **Validation:** 70% train / 30% validation split within 1992-2000
