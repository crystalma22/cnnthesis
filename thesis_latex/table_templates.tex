% 3. Format: S[table-format=X.Y] where X = digits before decimal, Y = after

% 5. Wrap significance stars in math mode: $^{*}$, $^{**}$, $^{***}$
% 6. Use threeparttable for notes (cleaner than manual \footnotesize)

% 8. Use \cmidrule(lr){X-Y} for partial horizontal lines under column headers
