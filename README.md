# CNN Stock Return Prediction: FOMC Event Study

This repository contains the replication code and data for the thesis "Convolutional Neural Networks for Stock Return Prediction: Evidence from FOMC Announcements."

## Overview

This study uses Convolutional Neural Networks (CNNs) to predict stock returns based on technical patterns in price charts, and examines how predictability varies around Federal Open Market Committee (FOMC) announcement dates.

## Model Specification

- **Architecture:** 2D Convolutional Neural Network
- **Input:** 20-day OHLC candlestick charts (I20)
- **Output:** Probability of positive return in next 5 days (R5)
- **Ensemble:** 5 independently trained models
- **Training Period:** 1992-2000 (in-sample)
- **Testing Period:** 2001-2024 (out-of-sample)

## Key Results

All results are generated by running `generate_updated_tables_and_figures.py`. The main findings are:

1. **Baseline CNN Performance:** Equal-weighted high-minus-low spreads of 70.74% annually (Sharpe ratio 5.60)

2. **Horizon Effects:** Predictability increases with horizon (0.87% at 1-day, 1.37% at 10-day)

3. **FOMC Effects:** CNN predictability collapses during FOMC weeks relative to matched control periods across all horizons (1-10 days)

4. **Size Concentration:** Effects are concentrated in small-capitalization stocks (equal-weighted spreads 3-10× larger than value-weighted)

- Python 3.9+

## Usage

To regenerate all tables and figures:

```bash
python generate_updated_tables_and_figures.py
```

Output files will be written to `thesis_output/tables/` and `thesis_output/figures/`.

## Data

The analysis uses:
- CRSP daily stock returns (2001-2024)
- FOMC announcement dates (2001-2024)
- CNN model predictions generated from 20-day candlestick charts
